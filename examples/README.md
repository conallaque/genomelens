# Examples

## [`genomelens_public_example.json`](genomelens_public_example.json)

A **public schema example**. It shows the shape of an integration payload — findings with dispositions, economic arms that each name a beneficiary and carry their own evidence basis, and explicit limitations — using synthetic values.

It is deliberately **not** a production payload. Production serialization carries internal state and identifiers that are not part of the public distribution, and reproducing that shape here would publish the machinery rather than the interface.

```
PUBLIC SCHEMA EXAMPLE · SYNTHETIC · NON-PRODUCTION
```

Terms used here are defined in [`../docs/GLOSSARY.md`](../docs/GLOSSARY.md). Values are illustrative and rounded. They are not benchmark results, not derived from any real genome, and not a claim about any person.
